Дескрипторы физического форматирования

< p > (Paragraph) — парный блочный дескриптор, который показывает начало и конец абзаца;
< b > (Bold) — парный строчный дескриптор, который делает текст жирным;
< i > (Italic) — парный строчный дескриптор, который делает текст курсивным;
< u > (Underline) — парный строчный дескриптор, который делает текст подчеркнутым;
< tt > — парный строчный дескриптор, который делает текст моноширным. Является устаревшим;
< s > (Strike) — парный строчный дескриптор, который делает текст зачеркнутым;
< sup > (Superscript) — парный строчный дескриптор, который делает текст верхним индексом;
< sub > (Subscript) — парный строчный дескриптор, который делает текст нижним индексом;
< big > (Big text) — парный строчный дескриптор, который делает текст большим. Является устаревшим;
< small > (Small text) — парный строчный дескриптор, который делает текст маленьким;

Дескрипторы логического форматирования

Являются аналогами дескрипторами физического форматирования, но лучше анализируются поисковыми машинами.
И для лучшего продвижения ресурса рекомендуют использовать именно их;

< strong > (Bold) — парный строчный дескриптор, который делает текст жирным;
< em > (Emphasize) — парный строчный дескриптор, который делает текст курсивным;
< code > — парный строчный дескриптор, который делает текст моноширным;
< mark > — парный строчный дескриптор, который выделяет текст фоном;
< ins > (Insert) — парный строчный дескриптор, который показывает вставленный текст;
< del > (Delete) — парный строчный дескриптор, который показывает удаленный текст;
< cite > (Citation) — парный строчный дескриптор, который оформляет цитату или название работы;
< abbr > (Abbreviation) — парный строчный дескриптор для сокращений;

Блочные элементы

< div > (Division) — универсальный блочный контейнер для группировки элементов;
< hr > (Horizontal Rule) — одиночный дескриптор горизонтальной линии (тематический разрыв);
< br > (Break) — одиночный дескриптор переноса строки;
< h1—h6 > (Heading) — парные блочные дескрипторы заголовков разного уровня;

Списки

< ul > (Unordered List) — парный блочный дескриптор неупорядоченного списка;
< ol > (Ordered List) — парный блочный дескриптор упорядоченного списка;
< li > (List Item) — парный блочный дескриптор элемента списка;

Ссылки и изображения

< a > (Anchor) — парный строчный дескриптор гиперссылки: пример ссылки;
< img > (Image) — одиночный строчный дескриптор вставки изображения;

Важно: Блочные элементы занимают всю доступную ширину и начинаются с новой строки.
Строчные элементы занимают только необходимую ширину и не переносят строку.
